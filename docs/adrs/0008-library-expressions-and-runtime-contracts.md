# 统一库表达式与运行时业务契约

文本模板和边表达式统一交给 Nunjucks 解析、求值，通用语法直接引用库文档，项目维护上下文及消费位置的业务契约。采用完整库表达式后，动态访问和变换后的数组未必能从声明中静态确定类型；相较裁剪语法或另建完整类型推导系统，本项目保留能确定的 Schema 引用与来源检查，将无法确定的结果结构留至运行时检查，明确不再保证编译时证明这类表达式的全部输入来源。

这项取舍不改变边 `if` 必须返回原生 boolean、`for` 必须返回带合法 `key` 的对象数组，以及 DAG 合并、输入允许缺失和提交回滚契约。Bash 还保留独立数据参数与自动 Shell 编码的消费限制。具体决定见[文本插值与表达式求值规格](../specs/text-expressions.zh.md)；本 ADR 记录已确认的设计方向，不表示实现或验收完成。
