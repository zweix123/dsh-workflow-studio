# 持久化工作流实例的运行图

工作流实例创建时保存固定的模板快照，并在宿主 `dsh-storage-domain` 中维护版本化实例运行图作为动态执行事实。运行图保存节点与 DAG 实例、执行位置、边的判定结果、已形成的实例连接及恢复所需的输入输出和身份；服务端从它恢复执行并生成前端画布投影。选择这一模型，是因为 `for` 和递归会让一个定义产生多个具有独立状态的实例，单靠模板或展示快照无法可靠恢复和定位它们。

模板的 `for` 边保持原定义。求值后保留逐项结果；等目标实例具备全部前驱并创建时，运行图形成与实际实例对应的连接。实例组完成后通过聚合输出连接下游，零项不产生实例连接。当前 DAG 引擎还没有状态导出与恢复接口，实施本决定需要补足该能力；现有宿主存储解决持久落盘，实例图的语义和校验仍由插件与引擎负责。
