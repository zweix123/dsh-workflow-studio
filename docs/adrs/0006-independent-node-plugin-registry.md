# 节点登记与公共契约独立成包

为支持用户提供可独立装配的节点插件，节点登记能力与公共节点契约从 Studio 独立成包，由 Studio、内置节点和第三方节点共同使用。相较继续由 Studio 提供登记入口，本次接受增加独立包的装配成本，使节点注册与模板注册形成相近的结构，且内置与第三方节点遵循相同的执行和 UI 协议。

这是[节点插件化注册](../specs/node-plugin-registration.zh.md)议题中已确认、尚待实施的决定，更新了 [ADR 0003](./0003-node-packages-and-contract.md)中“契约归属于 Studio、安装单元只有 Studio”的后续方向；原有节点业务控制权、宿主公开能力使用方式及工作流持久化分工继续沿用。模板资源声明、身份和名称沿用[模板分发规格](../specs/template-plugin-distribution.zh.md)，两份规格共同定义节点依赖与生命周期联动；具体包名和接口随完整契约收敛。

独立插件与默认安装体验分开处理：默认 bundle 统一声明 Studio、公共登记能力、三个内置节点及六份模板，用户添加一次即可获得基础能力；每项仍按公共插件机制装配，第三方节点和模板仍可独立提供。这样保留默认可用体验，不恢复 Studio 静态装配节点业务实现的耦合。
