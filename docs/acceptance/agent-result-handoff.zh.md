## 已修复的本轮失败

- 直接创建父 Agent 时，普通会话的模型选择不会自动安装。初版台后子执行缺模型配置；改用宿主公开 `agentDefaultModel` 并传入父 Agent 与台后子执行，台后真实链路复验通过。
- 后台父 Agent 原先没有挂载 Web 宿主默认预设，导致子执行缺少业务工具。现使用公开 agentPresets.resolve/mount 创建、恢复；真实子任务写读工作区产物复验通过。
- 固定 rc.1 原生 fork 不包含末次 turn/end 之后的手动压缩事件。已用真实宿主记录证实，交付前同步检测此边界并明确失败，要求继续并结束一个新轮次再重试；压缩进入已结束前缀后交付通过。
- 测试模板的重复出口字段、原生记录页没有选中普通列表行、宿主发送按钮的实际名称等定位/夹具问题已纠正；不作为当前产品失败结论。

## 剩余限制

确定性模型夹具证明宿主机制与应用状态机，不能证明真实模型能正确判断任务语义或在任意长度的压缩历史中交付结果。工作区文件不做快照，fork 不会恢复被压缩遮蔽的全部历史。末次完整轮次后手动压缩会明确拒绝交付，需先继续并结束新轮次。未增加旧实例兼容、自动结束、结束工具、取消或自定义 trace。

Standards 审查 0 项问题；Spec 首轮发现模板作者技能仍引用旧类型，已修复；补充 Agent 提交失败测试后复审，剩余 0 项。默认预设、压缩边界修复及双工作区场景均已独立复审通过。最终全量浏览器回归 18/18 通过；已说明的未验证项继续保留，不将部分通过写成整体验收通过。
