## 审查与证据

Standards 与 Spec 使用两个独立审查 agent，审查范围是工作开始文件基线到当前状态的变化（含未提交文件），不是整个工作区相对 HEAD 的差异。Standards 首轮发现 Agent 记录导航直接抛错会击穿交互；已改为公共 `reportError`，仅导航成功才关闭选择窗，并先红后绿补充可重试测试。复审无剩余发现。Spec 轴无发现。

可复现证据保留在上述仓库测试代码和夹具；运行报告、JUnit、步骤报告和脱敏宿主日志在 `.e2e/`（分轮保存在 `node-actions-initial-regression/`、`node-actions-second-regression/`、`node-actions-final-records/`、`node-actions-accepted-result/`；`node-actions-latest-results.json` 按用例汇总最后结果），完整检查日志保存在 `node-actions-check.log`，该目录不要求收入 Git。当前环境的临时 home、端口与进程只用于该轮复验，不作为长期唯一证据。Codex 内置浏览器人工检查用于确认原生浮窗与滚动，不能代替上述断言用例。

首轮失败适用于中间实现：长 Form 未限制 Modal 高度，底部字段不能操作；已增加原生 Modal 卡片高度约束和内容滚动并复验通过。DAG 整体中心命中被子节点遮挡，已改为标题区域检查并复验通过。旧回归的详情业务按钮与新界面不符，已迁为卡片入口并保留原业务断言。只读抽屉遮挡卡片时，关闭抽屉后操作卡片；OpenSpec 用例按实际用户动作更新。真实宿主运行期间不并行重建插件输出，避免热重载销毁当前页面。

## 限制

本轮真实宿主 Agent 场景使用确定性 adapter，不能宣称真实远端模型质量或真实 OpenSpec 技能执行已验证。浏览器覆盖记录中明确列出的行为；存储写入失败、宿主导航抛错和客户端卸载使用现有公开测试入口，不能归为真实浏览器注入验证。无新增草稿持久化；刷新、页面销毁与宿主重启仍会丢弃未提交草稿。
