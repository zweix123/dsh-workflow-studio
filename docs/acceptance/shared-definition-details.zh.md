自动化：相关图转换、导航与页面测试通过；完整 `rtk npm run check` 通过（类型检查、构建及 99 项测试）。组件测试覆盖递归与同名定义定位、长 prompt/schema/扩展字段、定义缺失提示、状态更新、等待位置消失、提交失败保留草稿，以及快照展示不请求模板接口。既有后端快照回归覆盖源模板删除与重启。
