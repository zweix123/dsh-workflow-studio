## 复现与范围

按照 [E2E 说明](../../e2e/README.md) 执行 `npm run test:e2e`。`.e2e/report.json` 保留逐步操作、断言与结果，`summary.md`、`junit.xml` 保留结果报告，`artifacts/` 保留失败诊断；这些临时产物不提交。行为可用同一已保存用例重验，不依赖截图或录像。

- 不包含真实模型回复、downstream 空 bash 命令的执行或外部副作用验证。
- 当前只验证 Chromium 中文桌面场景；英文、主题切换及窄屏组合尚未沉淀为可重复用例。
- 强制结束整个进程树或系统崩溃的回收未验证；这种情况下需核查本轮资源，不宣称自动清理成功。
- 初次编写时缺少欢迎层处理、创建后打开实例的操作，以及目录选择器初始扫描等待，曾导致测试准备失败；已修正用例，并在上述正向运行复验，不作为当前产品失败结论。
