## 环境与方法

macOS，Node 26.7.0、npm 11.19.0、pnpm 11.25.0，用户安装的 dsh 0.2.0-rc.1。每条浏览器用例复用 `e2e/dsh.ts` 创建独立临时 home、工作区及本机端口，通过真实 Chromium 操作宿主 UI；结束清理资源。默认无界面、不录屏、不主动截图；报告与脱敏宿主日志在 `.e2e/`，失败诊断由框架保留。没有读取日常模型凭据。

Agent 使用仓库既有确定性模型边界夹具，实际会话、子执行、只读页面、结构化输出、宿主重启及页面导航来自真实 rc.1。HTTP 集成测试补充归属查询不产生业务副作用、存储重开及删除失效。测试代码是长期复现依据，临时报告目录不是唯一证据。

## 限制

确定性模型边界不验证真实模型的任务语义或长上下文质量。本轮不增加独立 trace 页面，不自动继承任意宿主父子会话关系；只使用节点已保存的主会话与各次子会话身份。只读记录导航不等于任务重试或结果交付。
