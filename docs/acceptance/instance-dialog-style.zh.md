# 实例弹窗与宿主设置风格对齐验收

日期：2026-10-15。依据：[实例弹窗宿主风格](../specs/instance-tab.zh.md#弹窗宿主风格2026-10-15)。被测范围：`1102349` 之后本次对 Studio `styles.ts` 弹窗规则的修改。

本记录对应弹窗外壳轮次；之后的输入框、按钮及菜单统一与复验见 [UI 复核验收](./ui-style-review.zh.md#复核与修复验收2026-10-15)。

## 环境与变更

本机 `dsh 0.2.0-rc.1`，Node `v26.7.0`、npm `11.19.0`、pnpm `11.25.0`。复用 `e2e/dsh.ts` 的隔离宿主与本地回归夹具，不调用模型。

新建实例和删除确认共用宿主的 `bg-layer-2`、`radius-panel`、`elevation-prominent` 和 `bg-mask-1`，取消额外描边及窄屏圆角覆盖。遮罩与外侧留白遵循宿主顶部避让变量，默认至少留白 24px。保留各自内容尺寸和现有业务交互；输入框、按钮不在本次调整范围内。

本次沿用已有弹窗外壳，以保留删除确认的 `alertdialog` 语义和删除在途的关闭保护；宿主公开 Modal 的角色固定为 `dialog`，因此没有为样式调整改写这部分交互。外观规则直接采用宿主设置的语义变量。
