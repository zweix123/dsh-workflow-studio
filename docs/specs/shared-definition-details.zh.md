# 模板与实例共享定义详情

状态：已确认规格。本规格接续模板管理与节点卡片交互规格，更新实例详情正文的展示要求。

## Problem Statement

模板详情能够查看节点与 DAG 的直接配置字段，但实例详情主要依赖各节点类型的业务面板。用户无法在运行中的普通节点、DAG、等待或跳过位置查看它所依据的完整定义，难以将运行结果与创建时的配置对应起来。两套画布已共享渲染组件，展示类型与定义定位仍分散。

## Solution

模板与实例共享画布元素公共结构、定义引用和只读定义详情正文。实例继续按运行事实投影画布，在既有右侧抽屉中按上下顺序展示“运行信息”和“定义详情”。定义详情从实例创建时保存的 `detail.definition` 快照读取；源模板修改或删除后，既有实例仍展示原配置。

## Implementation Decisions

- 模板与实例的画布节点、边明确使用共同的展示类型；公共部分包含定义引用和渲染所需字段，实例部分保留运行身份与状态。两种图的转换逻辑分别处理静态定义和运行展开，不用模板图反推执行事实，不新增后端接口、持久化格式或通用节点继承体系。
- 定义引用使用从根定义出发的完整路径；根 DAG 对应空路径。嵌套、递归与同名节点不能仅凭定义 ID 定位。`for` 的各项实例引用同一份定义，同时保持各自实例身份、运行状态、输入输出及业务面板。
- 普通节点、嵌套 DAG、根 DAG、等待和跳过位置均可查看定义详情。实例页面标题区域新增“根 DAG 详情”入口，选择当前根实例；已有卡片仍只有详情按钮打开抽屉。根入口与卡片共用抽屉及已保存宽度。
- 实例详情的上部“运行信息”显示状态与可用的运行字段：实例 ID、父实例 ID、定义 ID、逐项身份、输入、输出。只展示对象实际具有的可选信息；根实例的父实例为空。等待与跳过位置没有实例 ID、逐项身份、输入或输出，只显示父实例 ID、定义 ID 和状态，不伪造实例。
- 运行字段中的状态、抽屉标题状态与画布保持一致：业务正在运行、执行错误或结果未知时显示对应状态，其余沿用 DAG 阶段状态；刷新后同步更新，不把失败或未知执行显示为就绪。
- 普通节点的已有业务面板保留在运行信息区，继续提供会话操作、命令结果与错误、表单填写和提交等能力。定义详情为只读，不提供脚本编辑、运行输入编辑或节点操作。切换查看对象、关闭重开、刷新运行数据时，既有页面内表单草稿继续按节点实例身份保留。
- 下部“定义详情”与模板复用同一正文组件，以 `dl` 字段列表按原直接字段顺序展示值。字符串完整展示，其他值以可阅读的 JSON 展示；字段名与内容不翻译。仅当对象类型为 DAG 时隐藏 `dag` 子项数组，普通节点的同名扩展字段仍展示；子项由画布分别查看。
- 定义定位失败时，保留已知运行信息，定义区显示“无法定位此对象的定义。”，不误用根定义或同名节点；不可定位的普通节点不装配依赖定义的业务面板。
- 保留既有抽屉宽度、键盘调整、关闭、点击画布空白保持打开和画布视口规则。所选实例更新后同步运行信息；所选等待位置消失时关闭抽屉，不自动改选新实例。
- 分区标题、字段标签、根入口和缺失提示随宿主中英文切换。共享正文沿用宿主主题，长文本及复杂值在宽窄屏、浅深色主题中可阅读；新增正文不扩大画布卡片。

## Testing Decisions

- 复用模板与实例组件测试，精确断言各分区及对应字段：普通节点、根/嵌套 DAG、等待/跳过位置的定义定位、字段顺序、长文本、schema、扩展字段和 DAG 子项隐藏。避免以整个抽屉文本代替分区断言。
- 覆盖源模板变化后实例仍显示快照且不请求模板详情接口；嵌套同名节点与递归定义定位；`for` 各项共享定义但运行身份、输入输出分别显示；等待位置消失关闭抽屉，状态变化同步。
- 保留会话操作、bash 输出/错误和表单交互回归；补充查看根 DAG 或另一节点后返回表单，草稿不丢失，提交失败保留草稿、完成后只读。模板详情始终不装配业务操作。
- 刷新普通节点的业务状态，精确检查运行区状态字段与抽屉标题一致，覆盖执行错误、结果未知、正在运行和 DAG 就绪阶段。
- 公共画布类型由生产调用端类型检查验证；既有图投影测试继续检查拓扑、分组、递归、逐项关系、布局与状态刷新，不固定绝对坐标。不重复新增已有源模板删除与重启快照测试。
- 实施中运行相关图与组件测试，交付前执行完整类型检查、构建和测试。按 `dsh-browser-e2e` 在固定 dsh `0.2.0-rc.1`、临时 `DSH_HOME`、非默认端口与 Codex 内置浏览器验收正常/错误路径、主题、语言、键盘和宽窄屏，逐项记录预期、实际及未验证项。

## Out of Scope

- 合并静态与运行图的生成算法、修改 DAG 语法或执行规则、重建通信协议及实例存储迁移。
- 运行实例编辑定义、原始 YAML 查看、模板热更新、结果手工编辑和新节点业务能力。
- 新增全局状态管理、表单草稿持久化或测试框架。
