# Form 填写浮窗

## 目标与范围

Form 的填写浮窗与固定版本 `dsh 0.2.0-rc.1` 设置浮窗保持一致。保留既有 Schema、数据、草稿、校验与结果交付语义；本规格只调整呈现与操作布局。

- 使用宿主 Modal 的遮罩、面板背景、圆角、阴影、焦点约束、Escape 和返回焦点行为。
- 使用宿主 Button、Input、Switch、Checkbox；原生枚举选择与多行输入采用设置字段的主题变量、字号、边框与圆角。
- 标题与关闭按钮固定在顶部；正文独立滚动；提交、交付重试与校验错误固定在底部。短表单按内容决定高度，长表单受宿主遮罩可用空间约束。
- 字段名称、描述、输入控件有明确层次；布尔字段左侧说明、右侧开关；对象以标题和细分隔线分组；数组每项独立展示并提供添加、删除按钮。
- 浅深主题、中英文、390px 窄屏均可操作，长名称和错误可换行，不产生横向溢出。
- 关闭保留同页面草稿；校验失败不推进节点；成功自动关闭；已接受结果的交付失败继续只读并可重试。规则见[节点操作位](./node-action-positions.zh.md)与[结构化表单](./form-structured-fields.zh.md)。

## 验收

| 场景 | 预期 |
| --- | --- |
| 对照设置浮窗 | 面板背景、圆角、阴影与字体一致，跟随主题 |
| 长表单滚动与窄屏 | 顶部标题和关闭、底部提交均不随正文滚走；无横向溢出 |
| 底部校验失败 | 错误与提交按钮同时可见，内容和草稿保留 |
| 键盘关闭、重开 | 焦点返回填写入口，草稿恢复；开关支持键盘 |
| 复杂数据提交 | 对象数组、枚举、多选、0、false、空容器及上下游交付行为保持有效 |

## 实施与验证状态

已实现。独立布局用例及 12 条受影响真实宿主回归通过，类型检查、构建与 176 条自动化测试通过；内置浏览器完成浅深主题及英文窄屏视觉检查。独立布局回归见 [dialog.e2e.ts](../../e2e/forms/dialog.e2e.ts)，实际结果见[验收记录](../acceptance/form-dialog.zh.md)。
