# 节点操作位与输入界面

状态：已实施（2026-10-13），验证进展见文末与[验收记录](../acceptance/node-action-positions.zh.md)。

2026-10-15 调整台前记录入口、台后文案及记录返回路径，本轮验证见[Agent 记录导航验收](../acceptance/agent-record-navigation.zh.md)。

## 已确认的设计边界

- 节点详情用于只读展示，不承担业务执行、完成确认或表单填写；节点级操作从节点卡片进入。允许复制字段、展开长内容和切换历史结果等只读浏览操作。
- 取消卡片上的独立“详情”按钮，点击节点卡片打开详情。操作按钮具有自己的行为，不能同时触发卡片详情。
- 节点卡片底部提供三个固定操作位。三个位置不绑定“主操作 / 完成 / 辅助入口”等业务含义，由节点类型定义动作。
- 插件明确指定动作属于第 1、2 或 3 位，允许中间或两侧留空；未使用的位置不触发其余按钮补位。
- 节点通过指定位置接入按钮；Studio 控制卡片公共外壳和按钮的统一展示，插件不改动公共布局。
- 按钮使用公共图标目录，显示“图标 + 文字”；尺寸、颜色和交互状态由 Studio 的统一组件控制。
- 节点插件负责按钮排列、显隐、禁用、交互和业务状态表达；Studio 继续负责节点在 DAG 中的位置、卡片公共外壳和编排状态。插件不能通过展示自行改变节点是否已完成编排的事实。
- Form 插件自行打开和管理输入浮窗，参考宿主配置的居中模态窗；Studio 不统一承载节点输入浮窗。输入浮窗与只读详情分开。
- 后台 Agent 的查看按钮采用“执行记录”，进入宿主原生执行记录；最终产出与待确认结果在只读详情中展示，“完成”独立负责确认并交付下游。

## 接入协议方向

基于现有公共动作声明增加明确的操作位和图标标识，沿用动作身份、文案、禁用状态及服务端／客户端动作分派，不新建另一套节点动作协议。

- 每个卡片动作声明 `position: 1 | 2 | 3` 和公共目录中的 `icon` 标识。单个节点的同一位置最多一个动作；未声明动作的位置留空。
- 公共图标目录复用固定版本宿主已有图标，节点选择图标标识，Studio 统一渲染。插件不为金刚位传入任意按钮组件或 SVG。
- 节点按业务状态返回各操作位动作，决定文案、显隐、禁用与目标。公共协议仍归属独立的 `dsh-workflow-node`，节点插件不依赖 Studio 的 DAG 或工作流内部类型。
- Form 的填写动作分派给客户端处理，由 Form 插件打开自己的输入浮窗；只读详情展示与输入浮窗生命周期分开，详情内容不获得业务动作或草稿编辑回调。
- 第三个位置是数量上限的一部分，不是强制的“更多”菜单；节点不能通过自行增加卡片按钮突破三个位置的约束。

公共类型与插件自管交互挂载方式见[节点作者指南](../node-plugin-authoring.zh.md)。

## 内置节点排位

| 节点状态 | 第 1 位 | 第 2 位 | 第 3 位 |
| --- | --- | --- | --- |
| Bash 首次可手动执行 | 执行 | 空 | 空 |
| Bash 失败或结果未知 | 重新执行 | 空 | 空 |
| Bash 业务成功、交付失败 | 重试交付 | 空 | 空 |
| Agent 尚未启动 | 执行 | 完成（禁用） | 空 |
| 前台 Agent 已创建对话 | 对话 | 完成 | 空 |
| 后台 Agent 已有执行记录 | 执行记录 | 完成 | 空 |
| 后台 Agent 执行失败或结果未知 | 执行记录（有尝试时；无地址则禁用） | 完成（禁用） | 重试 |
| Form 尚未提交 | 填写 | 空 | 空 |
| Form 结果已接受但交付失败 | 重试交付 | 空 | 空 |

- Bash 保留方块第 1 位的手动执行，抽屉不提供执行按钮；执行中禁用，失败或结果未知后可再次执行，节点成功完成后隐藏执行。沿用现有 `is_auto_start` 行为，不改为强制自动启动。
- Agent 的完成位保持在第 2 位；前台生成或交付执行中，以及后台尚无有效待确认结果时禁用。首次执行尚未创建对话或记录时不提供无效查看入口。
- DAG 已完成后隐藏执行、完成和重试等业务动作，已有台前对话与台后执行记录入口保留。Form 成功后的结果由点击卡片进入只读详情查看，不再次开放填写。
- 前台交付失败后保留对话，用户可补充材料后再次点击完成；后台任务失败或结果未知时，用户从第 3 位发起新的执行尝试。
- 已确认的 Agent 业务结果交付 DAG 失败时，第 2 位改为“重试交付”，仅交付既有结果，不重新执行任务。业务事实与 DAG 编排状态继续分开。

## Agent 记录导航

- 台前卡片不提供记录动作，第 3 位留空；各次结果提取从详情“运行记录”中的“交付记录”打开，主对话仍从第 1 位“对话”进入。
- 台后第 1 位“执行记录”直接打开最新一次尝试的原生记录，不出现多条选择浮窗；各次历史仍可从详情中的“执行记录”打开。
- 台后最新一次尚无地址或创建失败时，卡片入口禁用并提供原因，不回退旧地址；旧记录从详情历史访问。台前和台后历史中的无地址项只展示状态和错误，不提供无效导航。
- 历史只允许查看、复制和原生记录导航，不重建宿主 trace，不提供执行业务、确认、修改或重用旧结果的动作。
- 原生记录复用宿主的只读子会话界面，不新增 trace 页面；主对话和每次已保存地址的交付／执行记录均提供“返回实例”，按持久身份回到所属实例并打开对应节点详情。普通会话、用户自行 fork 的会话和台后隐藏父会话不自动关联；实例删除后不再提供有效返回入口。详见[会话返回规格](./session-agent-instance-navigation.zh.md)。

## 表单浮窗

- 关闭浮窗后保留当前页面的未提交草稿，重新打开继续填写；沿用既有刷新、页面销毁或宿主重启后丢弃未提交草稿的边界，不新增草稿持久化。
- 表单结果成功交付 DAG 后自动关闭浮窗；之后通过节点详情查看只读结果。
- 校验失败或交付失败时保留浮窗并展示反馈。服务端已经接受的结果不能再次编辑；交付失败时只允许重试既有结果，不重新收集或覆盖结果。

## 宿主参考依据

已只读核实实际安装的 `@deepseek-ai/dsh@0.2.0-rc.1`：全局配置齿轮打开居中模态窗；公共 `@deepseek-ai/dsh-client-ui-primitives` 出口提供 `Modal`、按钮、输入控件和宿主图标。

`Modal` 提供标题、滚动内容和底部操作区，关闭按钮、遮罩与 Escape 调用业务的 `onClose`，并处理焦点约束与关闭后的焦点恢复。它自身不决定草稿保存或丢弃；宿主配置表单的卸载丢弃行为不能直接当作 Form 的草稿规则。

原生 Modal 已在固定版本真实宿主中验证；详细结果见验收记录。

## 验收场景与预期

下表定义验收目标；逐项实际结果见验收记录。UI 行为应保存为独立可重复的真实宿主浏览器 E2E，用例自行准备前置数据。

| 场景 | 预期 |
| --- | --- |
| 第三方节点仅提供第 1 与第 3 位 | 中间留空，按钮不补位；使用统一的宿主图标、文字与交互样式 |
| 节点业务状态变化 | 插件可更新各位置的动作与禁用状态；卡片外壳、图位置和 DAG 编排状态继续由 Studio 管理 |
| 点击卡片或操作按钮 | 点击卡片内容打开详情，独立详情按钮消失；按钮执行其动作，不同时打开详情 |
| 嵌套 DAG 与子节点 | 检查容器不触发子节点业务；点击子节点不误选父 DAG；容器不提供普通节点执行动作 |
| 详情只读 | 可查看、复制、展开及切换历史结果；无执行、完成、填写或主对话按钮；可导航历史对应的原生执行记录 |
| Bash 手动与自动启动 | 保留方块手动执行和原有自动启动配置；抽屉无执行入口；执行、失败与完成状态遵守排位规则 |
| 前台 Agent 启动与完成 | 启动后第 1 位变为对话；第 2 位负责完成，生成或交付中禁用；第 3 位始终留空，详情历史提供各次“交付记录” |
| 后台 Agent 人工确认 | 第 1 位打开执行记录，详情展示待确认产出；仅点击第 2 位完成才交付下游 |
| 后台执行失败或结果未知 | 有效旧记录可访问，第 3 位提供重试；未经明确重试不重新执行 |
| Agent 已获准结果的 DAG 提交失败 | 完成位仅重试已保存结果的交付，不再次执行任务或交付模型调用 |
| 单条与多条 Agent 记录 | 台前全部从详情历史访问，台后卡片直达最新尝试；旧记录在详情历史访问，最新无地址时台后卡片禁用且不回退 |
| 主对话与原生记录往返 | 均显示返回实例；最新、旧的失败记录及重启恢复的记录准确返回节点，不触发完成、重试或新增尝试 |
| Form 复杂字段填写 | 填写打开 Form 自管浮窗，对象、数组、嵌套字段与原有校验保持有效，详情没有编辑控件 |
| Form 关闭与重开 | 关闭不提交、不完成节点；同页面重开保留草稿，刷新和重启不恢复未提交草稿 |
| Form 校验失败 | 浮窗继续展示错误并保留草稿，节点与下游不推进 |
| Form 已接受结果交付失败 | 浮窗保留反馈、结果只读；关闭后可从卡片第 1 位重试交付既有结果，不重新填写 |
| Form 交付成功 | 浮窗自动关闭，卡片无填写动作；点击卡片可查看只读结果，重启后结果仍保留 |
| 页面切换与插件生命周期 | 保留既有隔离、卸载后临时草稿丢弃及已保存结果恢复边界，浮窗与回调不跨节点串用 |
| 主题、语言、窄屏与键盘 | 中英文和浅深主题可用；三个位置与浮窗适应窄屏；节点及按钮可独立通过键盘操作，焦点与可读名称有效 |
