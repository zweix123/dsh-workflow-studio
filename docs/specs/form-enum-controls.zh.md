# form 枚举名称与多选规格

状态：2026-10-14 已实现；完整检查、3 条新增与 5 条受影响的既有真实宿主 E2E 均通过。实际范围与结果见[验收记录](../acceptance/form-enum-controls.zh.md)。

## 范围与规则

扩展现有 [form 结构化字段](./form-structured-fields.zh.md)，沿用 RJSF 的 `ui:enumNames`、枚举数组多选和 `ui:widget: checkboxes` 约定。公共 DAG 输出契约、节点动作、持久化与草稿接口保持现有语义。

- **选项名称。** 标量枚举允许 `ui:enumNames` 字符串数组（按 enum 下标对应）或对象（按枚举值的字符串形式对应）。允许部分覆盖，未配置的选项显示原值。数组不能多于枚举项数，对象不能包含枚举之外的键，名称必须是字符串；未声明 enum 时不能配置名称。名称只影响展示，默认、预填与正式提交仍使用真实值，不转换数字、布尔或字符串类型。不增加 oneOf、const 或 schema.enumNames。
- **唯一性。** 数组注解允许布尔 `uniqueItems`，省略或 false 保持原有行为；true 时前后端均拒绝重复值，错误定位到后一个重复项。支持标量、对象与嵌套数组；对象键顺序不影响相等判断，数组顺序参与相等判断。默认值同样校验；上游预填不静默去重，用户须明确修改后提交。此约束仅属于 form，不改变公共 DAG 类型规则。
- **多选。** uniqueItems 为 true 且 items 声明标量 enum 时，自动使用原生多选 select；数组级 ui:widget 可显式选择 select 或 checkboxes。未满足上述条件时不能配置数组控件。其他数组仍逐项增删，普通枚举数组仍允许重复。
- **数组名称定位。** 枚举元素名称配置在 uiSchema 的 items 中；多选数组也允许在数组级配置 ui:enumNames。遵循 RJSF 定位：提供 items 时从 items 读取名称，否则采用数组级名称。对象中的字段、对象数组中的字段与数组中的数组递归应用同一规则。
- **输入与输出。** 使用真实值初始化选中项，无整体默认值的数组从空数组开始；空数组合法，取消全部选择不恢复默认值。复选框新增选择追加到当前值末尾，取消保留剩余顺序；原生 select 操作产生选项声明顺序的值。未编辑的预填顺序保持原样。显示名称、选项索引与控件状态不进入结果。
- **交互。** 草稿在当前页面重开时保留，正式提交后只读；失败保留草稿，结果交付重试与宿主重启沿用已有确定结果。控件有可访问名称，支持键盘、中英文、浅深主题与窄屏，复用现有宿主主题变量与 Modal。

## 验收场景

| 场景 | 预期 |
| --- | --- |
| 字符串、数字 0、布尔 false 的枚举名称，含部分覆盖 | 界面使用配置名称或原值；提交与下游保持真实类型 |
| 对象内、普通数组元素、多选数组的名称 | 按声明位置递归生效；原有普通数组增删及重复值继续有效 |
| 名称类型错误、过长名称数组、未知映射键、无 enum | 模板判定失败 |
| uniqueItems 非布尔、重复默认值、非法数组控件 | 模板判定失败 |
| 自动多选 select、显式 select、checkboxes | 正确初始化、添加或取消选择；不展示逐项增删按钮 |
| 直接请求重复标量、对象键顺序不同的重复对象、嵌套重复值、非法选项或显示名称 | 服务端拒绝并指出字段或下标，不完成节点、不推进下游 |
| 重复上游预填 | 不自动改写；提交拒绝，重开保留，取消重选后可成功 |
| 清空多选与初始空数组 | 提交 []；不恢复默认选中项 |
| 成功交付、下游预填、真实宿主重启 | 值与类型准确，已接受结果只读，重启后恢复 |
| 键盘、中英文、浅深主题、390px 窄屏 | 操作与标签可用，表单无横向溢出 |
